# THS portal demo

Pixel copy of the THS Homeschooling portal for teacher, student, and parent logins.

Demo data is stored only in the current browser. The demo intentionally does not synchronize its plaintext fixture data to a shared backend.

Status-quo snapshot is tagged `statusquo`. Improvement work continues on https://new-ths.vercel.app.

## Demo logins

Fields on `/login` stay empty. Click a chip only if you want credentials filled.

- Teacher: `lehrer@ths-demo.schule` / `LehrDemo11`
- Student: `schueler@ths-demo.schule` / `SchuelerDemo11`
- Parent: `eltern@ths-demo.schule` / `ElternDemo11`

npm install
